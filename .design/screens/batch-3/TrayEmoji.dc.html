A curated EMOJI_OPTIONS constant, about 200 emoji at 9.6 KB, no dependency. Every one is Emoji 5.0 or below, so it draws on every device that can run Crumpet.
Why not a library: ios/Podfile:25 pins the deployment target to 16.4, and iOS 16.4 already ships Emoji 15.0 — so there is no rendering problem for a library to solve. The one maintained package last published in 2024, carries 2022 data, and sets state from a render body, which React Compiler cannot survive.
